# Épure

Launcher Android minimaliste : un écran d'accueil en texte seul, sans icônes, pour réduire le temps d'écran.

> Projet personnel en cours de développement. Inspiré de Minimalist Phone, dont il ne reprend ni le code, ni les textes, ni les visuels.

## Confidentialité

- Toutes les données restent sur le téléphone. Aucune collecte, aucun envoi, aucune statistique externe.
- L'application ne demande pas la permission `INTERNET` : elle ne peut pas se connecter à Internet.
- La sauvegarde Android est désactivée (`allowBackup="false"`) : les favoris et noms personnalisés ne sont pas envoyés vers une sauvegarde en ligne.

## Langues

Français par défaut ; anglais prévu en seconde langue.
